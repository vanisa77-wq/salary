# 薪資系統版面重整與配色調整紀錄（115/07/24～25）

本文件記錄這兩天針對 `index.html`（薪資計算器）進行的版面結構重整、蘋果圖示系統、配色系統調整。純粹是「畫面長怎樣」的紀錄，跟薪資計算邏輯無關；計算規則請見《月中到職離職_勞健保勞退計算規格.md》，部署方式請見《薪資系統說明書.md》。

---

## 一、版面結構：從單欄改成分頁

### 改動前
整頁由上到下一路排到底：LINE 回報 → Supabase 載入 → 員工資料庫連結 → 基本薪資設定 → 加班/津貼（可收折）→ 勞健保設定 → 請假設定 → 其它應扣 → 結果 → 年度統計，全部擠在一個直欄裡，桌面版一樣要一直往下捲。

### 改動後：5 個分頁 + 右側固定預覽欄
分頁列（`.calc-tabbar`）獨立在 `.layout-grid` 外面、橫跨整個上方，這樣左右兩欄才能從同一條線對齊：

1. **👤 基本資料**：Supabase 載入（左）＋員工基本資料庫管理（右，兩者並排）、下方是「貼上老師 LINE 回報」
2. **💰 應領薪資項目**：基本薪資設定（員工姓名/本薪/全勤獎金/計算年月/在職天數/到離職日/發薪日期/帳號末四碼）
3. **➕ 加班・津貼**：早晚值班登錄、親師會談加班費、超早晚值班、其它應領自訂項目（原本用 `collapsible-header/body` 做可收折，後來拿掉收合互動，改成固定展開）
4. **🛡️ 保險・扣款設定**：投保薪資級距、勞工保險／全民健保子卡片、追溯調整項
5. **📅 請假・其它扣款**：病假/事假設定、其它應扣自訂項目

**右側欄（`.col-preview`，`position:sticky`）**：應領/應扣結果卡片、實領金額總計、匯出/存檔 2×2 按鈕、年度統計紀錄（收合時整張卡片隱藏，不會留空框）。桌面斷點 `min-width:1080px` 才會左右分欄，手機版維持單欄堆疊。

### 過程中修正的結構性 bug
「貼上老師 LINE 回報」外層 `<div class="section">` 原本**少了一個對應的收合標籤**——這是舊版就存在的既有 bug，只是單欄版面下完全看不出影響。改成分頁後，這個缺口導致後面所有分頁內容（加班/保險/請假/右側預覽欄）全部被誤吃進「基本資料」這一層，造成分頁切換失效、右欄位置跑掉。已補上遺漏的 `</div>`，並用 Python `html.parser` 逐層驗證過巢狀結構正確。

## 三、圖示系統：emoji 全部換成蘋果切面圖案

原本用 📋👤💰➕🛡️📅🕐👨‍👩‍👧⚡✏️🖼💾📊🔄📇📡🧾 等 emoji 當章節/分頁/按鈕圖示，改成統一用您提供的蘋果切面插畫。

- 做法：CSS `.icon{font-size:0}` 把原本的 emoji 文字隱藏，`.icon::before` 用 `background:var(--icon-img)` 疊上蘋果圖片；一小段 JS（`ICON_MAP`）讀取每個 `.icon` 內原本的 emoji 字元，對應到不同的蘋果圖檔（`apple01.png`～`apple05.png`），確保同一種 emoji 每次都對應同一顆蘋果
- 最終定案：**5 顆**（從您提供的乾淨素材圖裡挑出完整、端正、不歪斜、去背正確的），圖示尺寸 32×32px，後面加一片半透明白底，確保放在任何顏色的按鈕/卡片上都看得清楚
- 素材檔案：`apple01.png`～`apple05.png`（部署在網站根目錄）

## 四、配色系統

### 色票來源
配色取樣自您提供的蘋果切面插畫，核心色票：
- 藏青 `#3F435E`
- 粉膚 `#FBC1B6`
- 芥末金 `#BF9241`
- 淺藍 `#BDE4E9`

### 目前套用規則
- **所有卡片最外層邊框**：統一 `2px solid #BF9241`（咖啡金），內部小元件（輸入框、日曆格、統計方塊、勞保/健保子卡片、表格儲存格）維持原本的淺灰邊框，避免整頁線條過花
- **應領項目**表頭：`#6FA6A3`（深青綠）、白字
- **應扣項目**表頭：`#D68C7A`（深磚橘）、白字
- **實領金額總計**：`#6B70A0`（深藍紫）、白字
- 各分頁卡片背景依分頁區分（已多次微調深淺，實際色值以線上版為準，此文件僅記錄配色邏輯與取色來源，不逐一列出每次微調的暫定色號）

### 已知需要注意的地方
- 卡片背景改深色/彩色後，卡片內文字顏色與虛線按鈕（`.add-btn`）背景需要跟著檢查對比度，`.add-btn` 已改回固定白底，不再透明帶出卡片色
- 若之後卡片背景色又調整，記得檢查該區塊內是否有寫死的文字顏色（例如 `.sec-title` 個別 inline `color` 覆寫）需要一併調整
